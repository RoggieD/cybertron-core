# Contributing to CyberTron C.O.R.E.

CyberTron C.O.R.E. is developed as an open-source project.

Contributions should:

- preserve modular architecture
- avoid embedded secrets
- avoid environment-specific assumptions
- include appropriate tests
- document major architectural changes
- preserve the external authorization model
- prefer permissive open-source dependencies

All code must be compatible with the project's license.
